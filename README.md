This project implements a complete movie recommendation system using the MovieLens 100K dataset. It includes three different recommendation approaches: user-based collaborative filtering, item-based collaborative filtering, and a graph-based Pixie-inspired random-walk algorithm. The project also includes extensive data analysis, similarity computation, graph exploration, and visualizations to support interpretation of the results.

Overview

The project fulfills all three required components of the assignment:

Data loading, cleaning, processing, and visualization

User-based and item-based collaborative filtering

Pixie-inspired graph-based recommendation using weighted random walks

The implementation is built in Python using pandas, NumPy, scikit-learn, and Matplotlib.

Dataset Description

The MovieLens 100K dataset contains:

943 users

1,682 movies

100,000 ratings

Approximately 93.7 percent sparsity in the user–movie rating matrix

Three files are used:

u.data: user–movie ratings

u.item: movie titles and metadata

u.user: user demographics

After cleaning, the data is exported as ratings.csv, movies.csv, and users.csv.

Why Visualizations Were Added

Visualizations play a crucial role in understanding the structure and behavior of the dataset. Since recommendation systems typically work with highly sparse matrices, visualizations help reveal patterns that are not easily noticeable from raw tables. For example:

Rating distribution graphs help determine user preferences and dataset balance

Heatmaps of similarity matrices clarify how users and items relate to one another

Scatterplots and histograms highlight sparsity and matrix characteristics

These visual representations support clear interpretation and justify why certain methods perform the way they do.

Part 2: Collaborative Filtering
User-Based Collaborative Filtering

Computes cosine similarity between users

Predicts ratings for unrated movies

Recommends movies highly rated by similar users

Item-Based Collaborative Filtering

Computes similarity between movies based on user ratings

Recommends movies similar to those a user has rated

More stable over time because item similarity changes less frequently than user behavior

Part 3: Pixie-Inspired Graph-Based Recommendation

This graph-based approach models users and movies as nodes connected by weighted edges. Edge weights represent normalized ratings, allowing the random walk to prefer highly rated connections. Recommendations are generated by counting weighted visits to movie nodes during the walk.

The graph structure captures complex pathways between users and movies, enabling the system to discover indirect but meaningful relationships.
